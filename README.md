**Leonida Trophy Atlas** — an offline trophy guide and tracker for Grand Theft Auto VI on PlayStation 5. All 55 official trophies with their names, descriptions and grades; a guide in the atlas's own words for every trophy, each citing its sources; a four-stage roadmap to the platinum; conservative missable flags built from the official descriptions, with the reason shown for each; and a checklist that saves to your device as you tick trophies off. Filter by kind (story, missable, collectibles, activities, online), grade or search text, show only unearned trophies, turn on the spoiler shield to hide unearned story trophies until you earn them, and export or import your progress as a JSON file. Everything runs from static files in `app/` — no build step, no network, your progress never leaves your machine.

## Run it

```sh
node serve.ts
```
then open http://localhost:8080 in a desktop browser.
